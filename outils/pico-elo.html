Pico Elo — Guide complet pour les animateurs

Mise en place initiale

1

Renseignez le registre avec le nom complet tel qu'il apparait dans Papi, l'ecole et l'age. Chaque nouveau joueur demarre a Elo 200. Un joueur absent du registre est ajoute automatiquement lors de l'import.

2

Exportez une premiere sauvegarde et rangez le fichier .json dans un dossier Google Drive partage. Ce fichier est la memoire du club d'un mois sur l'autre.

Apres chaque tournoi Pico (5 minutes)

1

Sur la page FFE du tournoi, selectionnez tout le texte (Ctrl+A puis Ctrl+C).

2

Chargez votre sauvegarde du mois precedent pour retrouver tous les Elo accumules.

3

Collez la grille, renseignez le nom et la date du tournoi, puis cliquez Analyser & Calculer.

4

Exportez la sauvegarde mise a jour pour le mois suivant.

5

Publiez le classement pour l'affichage au club ou sur le site. Imprimez-le directement via le bouton dedie.

Outils de gestion

🔀

Fusionner deux noms — si un meme enfant apparait sous deux orthographes differentes (ex : "DE RYCKE Alexandre" et "De Rycke Alexandre"), fusionnez-les. Les statistiques sont additionnees, l'Elo du nom correct est conserve.

📋

Signaler les absences — marquez un joueur comme absent pour un tournoi. Cela ne modifie pas son Elo mais conserve la trace dans l'historique.

📈

Graphique d'evolution — cliquez sur le nom d'un joueur dans le classement pour voir sa courbe de progression Elo mois par mois.

🖨

Impression directe — le bouton "Imprimer" formate le classement en A4 propre, sans passer par l'export HTML. Idéal pour le panneau du club.

La formule Elo Pico

Score attendu = 1 / ( 1 + 10 ^ ( (Elo_adv - Elo_joueur) / 400 ) )
Si victoire : Delta = 15 x (1 - Score_attendu) max +15 pts
Si defaite : Delta = 10 x (0 - Score_attendu) max -10 pts
Si nulle : Delta = 12.5 x (0.5 - Score_attendu)
Elo minimum garanti : 100 pts
Exemple : Lea (250) bat Thomas (180). Score attendu ≈ 0.60. Lea : +6 pts. Thomas : -4 pts.

Publier sur le site du club

Le fichier classement.html vient d'etre telecharge. Le site cannes-echecs.fr est deja configure pour l'afficher : il ne reste qu'a le mettre en ligne.

Chaque mois — 2 gestes

1

Placez classement.html dans le dossier du site Desktop\SiteACE, en ecrasant l'ancien fichier du meme nom.

2

Publiez le site (commande habituelle git push origin master:main, ou le raccourci que vous utilisez deja). Le classement apparait sur cannes-echecs.fr, onglet Tournois → PICO, quelques minutes plus tard.

C'est tout. La page du site s'adapte automatiquement a la taille du classement — rien d'autre a regler, aucun code a coller.
